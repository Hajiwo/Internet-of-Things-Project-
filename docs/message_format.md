# MQTT Sensor Message Protocol

This document defines the communication protocol between the Raspberry Pi (sensor side) and the Backend.

---

# General Format

Every MQTT message follows the same format.

```json
{
    "sequence": 1,
    ...
}
```

## Fields

| Field | Type | Description |
|------|------|-------------|
| sequence | int | Sequence number used to detect duplicated messages (QoS=1). |
| other fields | object | Message-specific payload fields at the top level. |

---

# 1. Temperature Sensor

## Topic

```
garage/sensor/temperature
```

## Payload

```json
{
    "sequence": 15,
    "temperature": 28.5
}
```

## Context Update

```
context.temperature
```

# 3. Parking Sensor

Each parking position has one corresponding button (or sensor).

## Topic

```
garage/sensor/parking
```

## Payload (Occupy)

```json
{
    "sequence": 8,
    "position": 2,
    "on_occupy": "true(occupy)"
}
```

## Payload (Release)

```json
{
    "sequence": 9,
    "position": 2,
    "on_occupy": "false(free)"
}
```

## Context Update

```
context.parking_occupied[position]
```

---

# 4. Vehicle Enter

Generated by the PC camera after successful license plate recognition.

## Topic

```
garage/camera/vehicle_enter
```

## Payload

```json
{
    "sequence": 30,
    "license": "BN9123",
    "enter_time": "2026-07-02T15:30:20"
}
```

## Context Update

```
context.current_vehicles.append(...)
```

---

# 5. Vehicle Exit

Generated by the PC camera when a vehicle leaves the garage.

## Topic

```
garage/camera/vehicle_exit
```

## Payload

```json
{
    "sequence": 31,
    "license": "BN9123"
}
```

## Context Update

```
context.current_vehicles.remove(...)
```

# Summary

| Topic | Purpose |
|------|---------|
| garage/sensor/temperature | Temperature update |
| garage/sensor/light | Light intensity update |
| garage/sensor/parking | Parking position occupied / released |
| garage/camera/vehicle_enter | Vehicle enters garage |
| garage/camera/vehicle_exit | Vehicle leaves garage |

---

# Notes

- Every topic maintains its own independent sequence number.
- `sequence` is used for duplicate detection because MQTT QoS=1 may deliver duplicate messages.
- The backend updates the `GarageContext` according to the received message.
- The parser only interprets the message; the `ContextManager` is responsible for modifying the context.
